# Where do we start?

A personal site and blog by Lee Rohrer about learning new things.

Built with [Next.js](https://nextjs.org/) and deployed on [Vercel](https://vercel.com/).

## Stack

- **Next.js 16** (App Router)
- **MDX** blog posts via `next-mdx-remote`
- **Tailwind CSS v4**
- **Geist** font
- SEO: sitemap, robots, JSON-LD, Open Graph
- RSS feed at `/rss`
- Dynamic OG images at `/og`
- Vercel Analytics & Speed Insights
